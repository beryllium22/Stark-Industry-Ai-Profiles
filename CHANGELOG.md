# Changelog

## 1.1.0

- Added Grok Bot authoring cards, persistent descriptions, extended playbooks, and synthetic starter tasks using the documented app workflow; no invented import manifest or share URL.
- Preserved all six exact screenshot baselines. Removed added roles from ULTRON's original-label field. Removed unsupported production-title attribution from the old README.
- Refined ownership, distinct working methods, pressure behavior, humor, evidence, approval, anti-injection, and bounded handoff rules. D.U.M.-E. does not deliberately fail; ULTRON can accept a sound design.
- Moved platform-neutral behavior to reviewed source files and generated both adapters deterministically.
- Removed user-specific troubleshooting examples from the public release. Shipped no live agent homes, credentials, account context, screenshots, or chat history.
- Omitted the old empty model value; Hermes config now selects only the native skin and leaves provider setup explicit.
- Strengthened installer validation, symlink rejection, file inventory, checksum verification, and redacted credential-pattern checks. Dry runs execute no Hermes process.
- Corrected update messaging: native update uses its recorded source, not necessarily the checksum-verified checkout. Explicit force options warn about replacing local config.
- Added regression tests and a read-only pinned-checkout CI workflow. Live Hermes, Grok app, model behavior, and native Grok share templates remain separately testable, not implicitly passed.
