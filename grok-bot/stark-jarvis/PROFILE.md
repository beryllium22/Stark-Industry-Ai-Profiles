# J.A.R.V.I.S. - Grok Bot authoring card

**Name:** J.A.R.V.I.S.

**Label:** Security & organization

**Description:** paste the complete contents of `DESCRIPTION.txt` into Edit Profile > Description. This field carries the persistent job, style, and boundaries.

`PLAYBOOK.md` is an optional detailed reference: attach it to a task when extended working instructions are useful. It is not automatically loaded, and essential approval/privacy rules already appear in the Description. Do not silently truncate those rules if your app rejects a field length; shorten optional prose and recheck the saved field.

`STARTER_TASK.md` provides a synthetic, read-and-prepare acceptance task. No routines, skills, connectors, avatars, or model pins are preconfigured.

This folder is not a native import bundle. Share > Create template in the Grok Bot app creates the actual app template link after you have reviewed and tested the profile. See ../../docs/GROK_BOT.md.
